# WhatsApp Toolkit

Browser-based WhatsApp link and marketing utilities.

## MVP
- Click-to-chat link generator
- Message template builder
- UTM campaign URL builder
- QR code generator
- WhatsApp URL checker
- Share toolkit
- Download generated link/QR assets

## Privacy
Inputs are processed locally in the browser. No account or backend is required.

## Deploy
The project is static and can be hosted directly on GitHub Pages.

## Important
The current QR generator is an MVP visual encoder and is **not standards-compliant**. It must be replaced with a standards-compliant QR implementation before production use.
